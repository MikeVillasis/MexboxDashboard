# UI sound cues

Drop 16-bit PCM `.wav` files here; they are copied next to the exe on build and preloaded at startup.
Any file that is missing is simply skipped.

| File                 | Played when                 |
|----------------------|-----------------------------|
| `blade_swoosh.wav`   | sliding between blades      |
| `channel_change.wav` | launching a game            |
| `navigate.wav`       | moving through a list       |
| `select.wav`         | pressing A / Enter          |
| `back.wav`           | pressing B / Esc            |

Use sounds you have the rights to (record your own, or use CC0 packs).
