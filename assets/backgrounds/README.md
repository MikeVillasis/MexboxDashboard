# Plaza sky references

Reference images the procedural skies in `src/Dashboard.App/WebAssets/js/scene/Sky.js` are modelled on. They are not
loaded at runtime (the skies are shaders); they're kept here so the look can be re-tuned against the original.

- `img/unsplash.jpg` → the "neon trails" sky. Photo by [Zak](https://unsplash.com/@zaks?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)
  on [Unsplash](https://unsplash.com/photos/blue-red-and-pink-abstract-artwork-7wBFsHWQDlk?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)
  ([Unsplash License](https://unsplash.com/license)). Credited in the plaza while that sky is on.
- `img/city-night.jpg` → reference for an upcoming sky (not in use yet). Downloaded from Unsplash as
  `mf-evelyn-QifOXDApdsw-unsplash.jpg`: [photo QifOXDApdsw](https://unsplash.com/photos/QifOXDApdsw) by mf-evelyn
  ([Unsplash License](https://unsplash.com/license)). Confirm the photographer's display name before crediting it in-app.
